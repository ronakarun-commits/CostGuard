# 1. Record architecture decisions

Date: 2026-10-10 · Status: Accepted

## Context
This is a portfolio project. Reviewers and interviewers care about *why* choices were made.

## Decision
Keep short ADRs (context / decision / consequences / alternatives) in `docs/adr/`, numbered.

## Consequences
Each non-obvious choice costs ~10 minutes to write up, and leaves a trail I can talk through in interviews.
